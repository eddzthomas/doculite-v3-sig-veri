# Glossary

| Term | Meaning |
|---|---|
| **Paperless document** | The document record and metadata owned by Paperless-ngx. |
| **Original** | The preserved uploaded file used for hashing and verification. |
| **Archive/OCR derivative** | A processed representation generated by Paperless; it is not substituted for the original in verification. |
| **Completed document** | The signed PDF retrieved from DocuSeal and imported as a new linked Paperless record. |
| **Verification** | Basic PDF-signature assessment by the approved verifier and trust policy. |
| **Integrity** | Whether signed content was changed after signing. |
| **Trust** | Whether a signer certificate chains to the configured trust policy. |
| **Provenance** | Whether DocuSeal recognizes a completed document it issued; this is not cryptographic validity. |
| **Signature request** | Product-owned record coordinating a source document with a DocuSeal signing submission. |
| **System of record** | Service that owns authoritative data: Paperless for documents/permissions, DocuSeal for active signing sessions, product database for mappings and reports. |
| **Customer stack** | A dedicated deployment, data stores, keys, storage, and backup boundary for one customer. |
