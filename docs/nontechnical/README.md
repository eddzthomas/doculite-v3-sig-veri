# Plain-language documentation

Each document in this directory mirrors one technical document elsewhere in `docs/`. These companions explain the same commitment in everyday language, focusing on what it means for customers, sponsors, reviewers, and operators.

`agents-guide.md` is the plain-language companion to the repository-root `AGENTS.md` used by AI agents and implementation contributors.

They intentionally do not replace the technical source of truth. Where a companion and technical document differ, the technical document and approved architecture decisions govern implementation.
