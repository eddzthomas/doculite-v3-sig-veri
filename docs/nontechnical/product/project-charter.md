# Project Charter: Plain-Language Version

We are creating a secure document hub for each customer. It will use Paperless-ngx to store and organize documents, DocuSeal to handle signing and basic signature checks, and our own web application as the main experience.

People will be able to upload, find, read, and share documents according to their permissions. They will also see whether a PDF signature appears intact and trusted under the customer’s settings, and can send documents out for signing.

The original upload is protected. A signed result is kept as a separate related document, never as a replacement. Each customer gets a separate environment and backups.

The first release is not a legal-compliance or “qualified signature” product. It gives clear basic PDF signature information and avoids making legal promises it cannot support.
