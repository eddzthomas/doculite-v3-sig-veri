# Glossary: Plain-Language Version

- **Original:** the file that was first uploaded. It is kept safe and used for checking signatures.
- **Signed copy:** the completed PDF returned after signing. It is linked to, not substituted for, the original.
- **Signature check:** a technical check of a PDF signature.
- **Trusted:** the signer’s certificate matches the customer’s configured trust list.
- **Provenance:** whether DocuSeal recognizes a document it created. This does not prove a signature is valid.
- **Signing request:** the record that tracks a document being sent to one or more people for signature.
- **Customer stack:** one customer’s separate application, data, keys, storage, and backup environment.
