# Information Architecture: Plain-Language Version

The main menu has four areas:

- **Documents** for upload, search, filters, and document lists.
- **Signing** for sending documents and tracking signatures.
- **Administration** for settings and service health for authorized staff.
- **Account** for personal account and sign-in settings.

Each document page puts the important actions and preview first, then its details, signature result, related signed copies, and history. People only see documents and actions that their existing Paperless permissions allow. External signers do not enter the document hub; they use the signing service.
