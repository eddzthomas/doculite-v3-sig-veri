# Design System and Accessibility: Plain-Language Version

The application will use familiar, consistent controls for lists, filters, uploads, previews, status labels, confirmation messages, and errors.

It will aim to work well with keyboard-only use, screen readers, zoomed text, narrow screens, and high-contrast needs. Important status information will be written in words and shown with more than color. On phones, details and filters will reorganize so that important actions and document information remain easy to reach.
