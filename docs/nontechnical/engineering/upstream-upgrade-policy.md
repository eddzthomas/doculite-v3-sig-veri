# Upstream Upgrade Policy: Plain-Language Version

Paperless and DocuSeal are outside projects that release updates on their own schedule. We lock approved versions, read update notes, and test updates in a safe rehearsal environment before using them for customers.

Every upgrade checks document management, signature checking, signing, permissions, backups, and the ability to roll back. We only create a maintained fork of an upstream project when there is no supported alternative and when there is a clear plan to keep that fork secure and up to date.
