# Test and Acceptance Plan: Plain-Language Version

We test small pieces of code, connections between services, real browser journeys, security controls, and recovery procedures.

Before release, we prove that permitted users can manage documents, unauthorized users are blocked, signature results are shown correctly, signing works even when a notification arrives twice, and failed checks do not pretend to be successful. We also practice restoring a complete customer environment from backup.

The release stops if there is an unresolved serious security or document-integrity problem.
