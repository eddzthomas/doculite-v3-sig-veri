# How the System Fits Together

**Status:** Draft for stakeholder review

This product combines two specialist tools with a new, easier interface. Paperless-ngx is where the organisation's documents live and where access to them is controlled. DocuSeal runs the signing process and checks PDF signatures. Our own application is the front door that brings these capabilities together.

The three systems stay separate. This makes upgrades safer and avoids turning one system's internal data into another system's responsibility. Our application keeps only the links and history needed to coordinate the experience.

Each customer has a separate installation and separate data. A signed copy is kept alongside—not instead of—the original document.
