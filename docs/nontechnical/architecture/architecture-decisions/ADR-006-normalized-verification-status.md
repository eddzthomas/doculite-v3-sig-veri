# Decision: Use Clear, Consistent Signature Results

**Status:** Draft for stakeholder review

The product will use five simple result labels: unsigned, valid and trusted, valid but untrusted, invalid, and unable to check.

It will keep separate details about whether the file came through DocuSeal, whether the file looks unchanged, and whether the signer is trusted. This avoids presenting a misleading “all good” label when only one of those things is true.
