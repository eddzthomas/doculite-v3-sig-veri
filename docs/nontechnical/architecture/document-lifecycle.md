# What Happens to a Document

**Status:** Draft for stakeholder review

When someone uploads a file, it goes into the document-management system, which processes and indexes it so people can find it. The product then records that document's reference and can ask the signing service to inspect its PDF signatures.

If signing is requested, the signing service manages the recipients and signing process. Once everyone is finished, the completed PDF is added back to the document-management system as a new, connected document.

The original file is never overwritten. This gives users a clear record of what existed before signing and what was returned after signing.
